Live Scenario

กรณีเบิกค่าใช้จ่ายรายการใหม่ ต้องเริ่มตรวจอะไรเป็นลำดับแรก?
เริ่มจากตรวจประเภทเงินงบประมาณ วัตถุประสงค์การเบิก ผู้รับเงิน เอกสารประกอบ และความเชื่อมโยงกับระเบียบที่เกี่ยวข้อง จากนั้นให้ส่งตรวจโดยผู้มีอำนาจก่อนทำรายการในระบบ แหล่งอ้างอิง: ฐานความรู้กลาง / คู่มือหน่วย / หนังสือเวียนที่ผ่านการยืนยัน
Research Logic

กรอบแนวคิด Input - Process - Outcome

Input

สภาพปัญหา ข้อมูลระบบงาน ระเบียบ คู่มือ เอกสารฎีกา ประสบการณ์จริง และข้อผิดพลาดที่พบในการปฏิบัติงาน

  • กำลังพลหมุนเวียน
  • งานเบิกจ่ายและบัญชีซับซ้อน
  • องค์ความรู้กระจายอยู่กับบุคคล

Process

วิเคราะห์ด้วยทฤษฎีที่เกี่ยวข้อง ๕ กลุ่ม เพื่อออกแบบแนวทางที่ตรวจสอบได้และใช้ได้จริงในงานราชการ

  • Artificial Intelligence: AI
  • KM/SECI, Bloom, Competency
  • PESTEL/SWOT

Outcome

แนวทางพัฒนาระบบการเรียนรู้และการจัดการองค์ความรู้ด้วย AI โดยมีมนุษย์กำกับและมีหลักฐานอ้างอิง

  • AI Knowledge Assistant
  • Checklist และ Learning Path
  • สมรรถนะบุคลากรสูงขึ้น
1AIค้นคืน อธิบาย แนะนำ และฝึกสถานการณ์
2KM/SECIแปลงความรู้จากคนสู่ฐานความรู้กลาง
3Bloomจัดลำดับการเรียนรู้ตามระดับความเข้าใจ
4Competencyกำหนดสมรรถนะเป้าหมายของบุคลากร
5PESTEL/SWOTวิเคราะห์บริบท โอกาส และข้อจำกัด

Human in the loop

กรณีมีผลต่อการอนุมัติ การตีความระเบียบ หรือข้อมูลเฉพาะ ต้องส่งผู้มีอำนาจตรวจสอบ

Reference first

คำตอบต้องอ้างอิงระเบียบ คู่มือ หนังสือเวียน หรือฐานความรู้ที่ยืนยันแล้ว

Data protection

ไม่ใส่ข้อมูลส่วนบุคคลหรือข้อมูลราชการอ่อนไหวในระบบที่ไม่มีการควบคุม

Audit trail

บันทึกคำถาม คำตอบ แหล่งอ้างอิง และผู้ตรวจสอบ เพื่อใช้ปรับปรุงฐานความรู้
